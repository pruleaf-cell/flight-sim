Controls

  • W / S: pitch down / up
  • A / D: roll left / right
  • Q / E: rudder left / right (and nosewheel steering)
  • Arrow Up / Arrow Down: throttle
  • F / V: flaps increase / decrease
  • [ / ]: trim nose down / up
  • Space: wheel brakes
  • B: parking brake toggle
  • I: engine start / stop
  • C: camera view
  • P: pause
  • R: restart run
  • H: toggle HUD help cues
